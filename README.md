📚 College Library & Online Book Store

About the Project

This is a basic HTML-based College Library and Online Book Store Website developed as an academic project during my Second Year, Third Semester.

The project represents a simple concept of how a college library website could be organized to provide students with access to books and library-related sections.

🛠️ Technology Used

- HTML (HyperText Markup Language)

✨ Main Sections

1. Login Page – A basic login interface for the library website.
2. Book Store – A section representing the online book store.
3. Shopping Cart – A page representing the cart section.
4. Book Catalogue – A section for displaying the book catalogue.
